# 第一版验收场景

## 固定环境

- Minecraft 1.21.1 / NeoForge 21.1.256。
- LittleTiles pre233 / CreativeCore 2.13.50。
- Sodium 0.8.13-beta.2 / Iris 1.8.14-beta.1。
- 当前 INCEPTION 1.21.1 alpha4 材质包。
- 光影开启场景使用 iterationRP Alpha 0.4.2。

使用独立测试世界。旧 1.12 Genesis 世界作为效果参照，未经迁移不直接打开。

## 自动检查

- 256 种 CTM 边与角组合，恰好覆盖 47 个索引；无两条相邻边时对角连接不产生效果。
- 六个面的 repeat 朝向、负坐标和跨越原点；改变一个完整周期后选图相同。
- random 在刷新前后保持稳定，零权重的贴图不会被选中。
- vertical 的独立、上接、下接、上下接四种排列。
- 规则解析、相对 / 绝对路径、透明占位、错误属性拒绝和范围上限。
- 实际材质包全部规则、贴图引用以及法线 / 反光兄弟资源。

## 游戏场景

1. **大面积纹理**：8×8、4×4 的普通方块面，旁边用同材质 LT 面复制。比较六个朝向和负坐标，裁切后不得变成每格重新起始。
2. **玻璃 CTM**：单块、两块、一圈、缺边、缺角、斜角。普通玻璃与 LT 同材质相邻时使用相同连接语义。
3. **混合容器**：一个 LT 方块内放两种材质。只有匹配材质参与连接；保留旧版“容器包含材质”的语义。
4. **模型面**：玻璃板等 unculled 面不消失；切割、斜面、挖空后的外露面不被当作完整立方体遮挡。
5. **编辑刷新**：修改当前格和对角邻居，撤销、拆除、重新放置。纹理及时更新，资源重载后无旧图集 UV。
6. **随机材质**：重进世界、资源重载、移动相机，选图稳定。
7. **光影**：同场景分别关闭 / 开启 iterationRP。观察法线、反光贴图、透明玻璃、材质 ID 与阴影。
8. **性能**：连续编辑大量 LT，检查队列完成、闪烁和缓存增长；比较开启 / 关闭纹理模组的区块重建时间。

## 已知边界

- `_e` 独立发光叠加尚未完成；其他渲染器的生物群系视图需要分别验证。
- 1.12 彩色玻璃的数字 ID 与 metadata 要转成现代方块 ID。
- 移动结构、PTGI、光影专用的彩色光和体素反射单独记录，不用普通阴影通过来代替其验证。
- 游戏启动通过只说明资源加载和 Mixin 接入通过，不代表以上场景全部通过。
